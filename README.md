# RSH — Reel Story Hub | GitHub Pages Starter

A static, single-page portfolio prepared from your approved RSH HTML prototype.

## Publish it using GitHub's website (no terminal required)

1. Create or sign in to a free account at https://github.com/.
2. Go to https://github.com/new and create a **Public** repository. Recommended name: `rsh-website`.
3. In that repository, choose **Add file → Upload files**.
4. Upload **index.html**, **favicon.svg**, and **.nojekyll** from this folder. (The hidden `.nojekyll` file is optional.)
5. Select **Commit changes**.
6. Open **Settings → Pages** in the repository.
7. Set **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**, then **Save**.
8. Once GitHub finishes publishing, open `https://YOURUSERNAME.github.io/rsh-website/` and test it on desktop and mobile.

The repo name `YOURUSERNAME.github.io` instead of `rsh-website` produces the shorter homepage URL `https://YOURUSERNAME.github.io/`.

## Before treating it as the final public portfolio

- Replace the placeholder showreel modal with your actual reel (an embedded YouTube or Vimeo video works well).
- Replace illustrative creative-focus cards with thumbnails/links to real completed work; don't imply mockups are actual client projects.
- Check the LinkedIn URL and add the actual email or WhatsApp contact you want visitors to use.
- Update your work samples as you add projects.
- Review all images/media and ensure you have the right to publish them.

This template does not need Node.js, Python, or a server. It uses inline CSS, JavaScript, and embedded logo images. The Montserrat font is loaded from Google Fonts, with fallback fonts.

GitHub Pages is for static pages, not server-side forms, online payments, or hosting large videos. Link to your YouTube/Vimeo portfolio instead of storing large video files in GitHub.
